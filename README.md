IP Calculator
==================

[![LICENSE](https://github.com/developer-kaczmarek/IpCalculator/blob/main/images/license-GPLv3-blue.svg)](https://github.com/developer-kaczmarek/IpCalculator/blob/main/LICENSE)

IP Calculator is a simple tool that helps you quickly work with networks. We rebuilt it from scratch with a fresh design and modern technologies, giving it a fresh look and smoother experience.  

The app now supports edge-to-edge content, adapts to different screen sizes and works great in both portrait and landscape modes.  

Everything you need is right on one screen: quick calculations and an easy way to share them. Designed to save your time.

## Features

### Calculator Screen
- Calculate subnet mask and wildcard mask  
- Determine network and broadcast addresses  
- Show total number of addresses and usable hosts  
- Find first and last host IP addresses  
- Share results via messenger or copy as text  

### Info Screen
- Access useful links:
  - GitHub repository  
  - Privacy policy  
  - Rate the app  
  - Option to share the app  
  - Contact the developer  

### Settings Screen
- Language selection: English, Russian, Kazakh  
- Theme selection: System default, Dark, Light  

### Error Reporting
- If an error occurs, the app displays a Snackbar with an option to send the error details directly to the developer
